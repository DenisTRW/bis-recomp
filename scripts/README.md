# scripts

Helper scripts used during development.

| Script | Purpose |
|---|---|
| `insn_stats.py` | instruction statistics over the disassembly in `build/asm` |
| `scan_consts.py` | search for constants in the disassembly |
| `rename_symbols.py` | rename symbols in the dsd configuration |
| `ghidra*.bat`, `ghidra/*.java` | optional Ghidra project setup and analysis helpers |
