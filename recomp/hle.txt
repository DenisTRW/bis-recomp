# HLE-Ersatz für einzelne Funktionen
#
# Format:  <dsd-Name>  <C-Funktion>  <Kategorie>  <Beschreibung>
#
# Der Recompiler übersetzt die Original-Funktion trotzdem (als rc_orig_<Name>),
# rc_<Name> ruft aber die C-Funktion hle_... auf. Der Ersatz kann das Original
# weiterhin aufrufen (z. B. als Hülle drumherum).
#
# Kategorie wie im Laufzeit-Bericht: ORIGINAL (gleiches Verhalten, nur anders
# umgesetzt), SIMULIERT (bewusst vereinfacht), FEHLT.
